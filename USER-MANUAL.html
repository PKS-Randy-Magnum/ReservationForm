1. What this system is

This is an online form that collects wedding room-block details for The LaSalle Chicago.

It replaces chasing answers by email or paper. Couples fill out the form. Staff can start or review a draft. When the couple submits, the hotel gets an email with a PDF summary.

What it does (in plain English)

  • Locks the form behind an access code
  • Lets people save progress and come back later
  • Stores answers in a Microsoft list (SharePoint)
  • Emails the couple a resume link when they save
  • Emails the hotel a PDF when they submit final
  • Lets staff unlock with a staff code to edit without spamming emails
You do not need to run a server The form lives on GitHub Pages. Saving and emailing are handled by Microsoft Power Automate and SharePoint.

3. How couples use the form

Give the couple: (1) the form link, and (2) the guest access code.

  1. Open the link in Chrome, Edge, or Safari.
  2. Enter the access code from the hotel, then unlock.
  3. Fill in contact details (name, wedding date, email). Email is needed so they can get a resume link.
  4. Click Save progress anytime. They get an email with a link to continue later. Nothing is final yet.
  5. Click Submit final when everything is complete. They should see a thank-you screen. The hotel gets the PDF alert.
What guests must fill before Save Couple/party name, wedding date, and email.
What guests must fill before Submit The full form. If they answer No to valet, bags, brunch, or getting-ready room, they can skip those detail boxes. Ceremony time, reception time, and group arrival/departure are always required on submit.
Within 30 days of the wedding A red banner warns that late requests may not be assured. Complete-by still defaults to 30 days before the wedding date.

4. How staff use the form

Staff use a different password (staff code). After unlock you should see a gold banner: Staff mode.

Recommended: staff starts the draft

  1. Open the live form (optionally with dates already in the URL — see Links).
  2. Unlock with the staff code.
  3. Enter at least couple name and wedding date.
  4. Click Save progress. No customer email is sent for staff saves.
  5. Copy the link from the browser address bar, or open the SharePoint list and copy Form URL.
  6. Send that link + the guest access code to the couple.

Open a draft while the couple is still working

  1. Open the Wedding Room Planner list in SharePoint.
  2. Find the couple. Click Form URL (or paste ?draft=… onto the form link).
  3. Unlock with the staff code.
  4. Edit and Save. List updates; couple is not emailed again from a staff save.

After the couple submits

  • Staff get an Outlook email with a PDF summary.
  • List status becomes submitted.
  • Staff can reopen the form, edit, and submit again to refresh the PDF without another email (staff path).
Staff-only section on the form “Important dates at a glance” is hidden from couples. Those dates auto-fill from the wedding / complete-by date (cutoff & menu = complete-by; vendor list = wedding − 14 days; gift bag = day before wedding).

7. Passwords — what they are & how to change them

There are two codes. Both live inside Power Automate — not on the public website.

CodeWho uses itCompose name in the flow
Guest access code Couples (and anyone you invite as a guest) FormPassword
Staff code Hotel employees only StaffPassword

How to change a password

  1. Open make.powerautomate.com and sign in with the hotel Microsoft account.
  2. Open My flows → Wedding Room Block Form - API → Edit.
  3. Near the top of the flow, find the Compose step named FormPassword (guest) or StaffPassword (staff).
  4. Click that Compose. In the Inputs box, delete the old code and type the new one (plain text — no quotes needed).
  5. Click Save (top right). Confirm the flow stays On.
  6. Tell the people who need it the new code. Old codes stop working immediately.
  7. Test: open the live form and unlock with the new code.
Do not put live passwords in GitHub Anyone can view the public site files. Keep real codes only in Power Automate Compose steps.
Staff vs guest unlock The flow’s password Condition should accept either FormPassword or StaffPassword. Staff unlock returns staff: true so the form shows staff-only fields and stays quiet on save/submit.

9. Edit a SharePoint column & reconnect Power Automate

The list stores answers. Power Automate is the bridge that writes into that list. If you change a column in the list, you must also tell the flow about it — or Save will fail or leave the cell blank.

Why two places?

PlaceWhat it doesExample
SharePoint list
Wedding Room Planner		 Holds the columns (like spreadsheet headers) and the rows of wedding data Add a column “Guest Rooms”
Power Automate flow
Wedding Room Block Form - API		 When someone Saves or Submits, writes each form answer into the matching list column Map “guests” → Guest Rooms
Golden rule Changing only the list is not enough. Changing only the flow is not enough. Do both, then test Save on the form.

Step A — Open the list

  1. Sign in to Microsoft 365 with your hotel account (same one that owns the list).
  2. Go to SharePoint (or Microsoft Lists).
  3. Open the list named Wedding Room Planner.
  4. You should see one row per wedding (draft or submitted), with columns like Couple Name, Draft ID, Form URL, Status.

Step B — Add or edit a column

  1. At the far right of the column headers, click + Add column (or open an existing column’s menu → Column settings → Edit).
  2. Choose the type carefully:
    • Single line of text — names, times as text, Form URL
    • Multiple lines of text — long notes, FormPayload
    • Number — guests, vehicles, attendance
    • Date and time — wedding date, arrival (prefer Date only when possible)
    • Choice — yes/no or valet payment options (use the exact choice values the form sends)
  3. Give it a clear name (example: Guest Rooms). Click Save.
  4. Optional: drag the column where you want it in the list view.
Rename tip Renaming a column in SharePoint usually keeps the link in Power Automate, but always open Create/Update afterward and confirm the field still shows. If it vanished, re-map it.

Step C — Open the Power Automate flow

  1. Go to make.powerautomate.com (or Power Automate in the Microsoft 365 app launcher).
  2. Click My flows (or Solutions if your team keeps it there).
  3. Open Wedding Room Block Form - API.
  4. Click Edit.

Step D — Link the new column in Create item & Update item

The flow has SharePoint steps that write the list. You must update every Create and Update that should fill this column (usually Save draft and Submit final — both Create and Update branches).

  1. Find a Create item step for Wedding Room Planner. Click it.
  2. If your new column is missing from the form, click Show all / refresh the fields (or delete and re-add the Create item action so SharePoint reloads the column list).
  3. Find your new column. Click in the value box → open the dynamic content / expression picker.
  4. Map it to the matching form field (examples from the field map):
    • Guests → guests
    • Email → email
    • Wedding Date → wedding_date
  5. Repeat for the matching Update item step(s).
  6. Repeat for Submit-path Create/Update if those are separate actions.
  7. Click Save on the flow. Leave the flow On.
Dates & numbers that can be blank Copy-paste formulas that send null when empty: Section 11.
Choice columns Do not wrap yes/no choice values with int(...). Choices are text (for example yes / no). Details in Section 11.

Step E — Test

  1. Open the live form → unlock with the staff code.
  2. Fill the related fields → click Save progress.
  3. Open the SharePoint list → open that couple’s row → confirm the new column has the value.
  4. If blank or Save errors: Power Automate → Run history → open the failed/latest run → expand the Create/Update step and read the red error.

Mini flow (remember this)

Open list→ Add/edit column→ Edit flow→ Map Create + Update→ Save flow→ Test form Save

10. Change emails & add notification recipients

When a couple submits, hotel staff get an Outlook email (usually with the PDF). You control who is on that list inside Power Automate — not on the website.

Which email steps exist?

EmailTypical step nameWho it goes to
Resume link (guest Save) Send an email on the guest draft path The couple’s email from the form
Submit alert + PDF Send an email (V2) Submit (or similar) Hotel staff — this is the one you edit for notifications
Staff Save / Staff Submit (none on purpose) Nobody — silent by design

Change the main notification address

  1. Open Power Automate → Wedding Room Block Form - API → Edit.
  2. Scroll to the submit path. Find Send an email (V2) used after the PDF is ready (often named with “Submit”).
  3. Click that action.
  4. In the To field, replace the address with the correct hotel mailbox (example: Hongyu.Dai@thelasallechicago.com).
  5. Optional: edit Subject and body text (keep it professional; the PDF is usually an attachment).
  6. Click Save. Keep the flow On.
  7. Test with a staff unlock first if you only want a PDF refresh, or a guest submit if you need a real notification email.

Add more people to receive notifications

Pick one approach. The first is simplest.

Option A — Several addresses in To / Cc (easiest)

  1. Open the same Send an email (V2) Submit action.
  2. In To, enter multiple work emails separated by a semicolon: 
    person1@thelasallechicago.com; person2@thelasallechicago.com
  3. Or put one primary in To and others in Cc or Bcc (click Show advanced options if Cc/Bcc are hidden).
  4. Save the flow.

Option B — Shared mailbox or distribution list (best for teams)

  1. Ask IT to create a shared mailbox or Microsoft 365 Group (example: weddingblocks@thelasallechicago.com) and add the people who should see alerts.
  2. Put only that one address in the flow’s To field.
  3. Add/remove people later in Outlook / Microsoft 365 admin — no flow edit needed each time.
Tip Prefer a shared mailbox or group when several coordinators need every PDF. Then you are not editing Power Automate every time someone joins or leaves.

Guest resume email (usually leave alone)

The Save-progress email goes to whatever address the couple typed. You typically do not hard-code recipients there. If that step fails, check Run history → the Send email step for that run.

Staff path stays silent Do not add a staff notification email unless leadership asks for it. Staff Save/Submit were built to update the list/PDF without inbox noise.

11. Safe expressions (dates, numbers, empty values)

SharePoint is picky. If a date or number field is empty on the form and Power Automate sends a blank text box (""), Save can fail. The fix is a short expression: “if empty, send null; otherwise send the value.”

What is an expression?

An expression is a small formula you paste into a field instead of picking a value from the dynamic content list. In Power Automate:

  1. Open a Create item or Update item action.
  2. Click the box for the SharePoint column (example: Group Arrival).
  3. Click the fx (Expression) button — usually next to the dynamic content panel.
  4. Paste one of the formulas below → click OK / Add.
  5. Save the flow, then test a Save with that field left blank and with a value filled in.
Where form values live Most answers sit under the trigger body payload. The pattern looks like: json(triggerBody())?['payload']?['field_name'] Replace field_name with the real key (examples below).

Dates (and date/time) — null if empty

Use this whenever a date can be blank on a draft Save (Group Arrival, Group Departure, Brunch Time, etc.).

Group Arrival example — paste into the Group Arrival column:

if(empty(json(triggerBody())?['payload']?['group_arrival']), null, json(triggerBody())?['payload']?['group_arrival'])

Group Departure:

if(empty(json(triggerBody())?['payload']?['group_departure']), null, json(triggerBody())?['payload']?['group_departure'])

Brunch date/time:

if(empty(json(triggerBody())?['payload']?['brunch_datetime']), null, json(triggerBody())?['payload']?['brunch_datetime'])

Plain English: If the couple left it blank, write nothing (null). If they filled it, write that date.

Numbers — null if empty (not int on blanks)

For optional number columns (vehicles, brunch attendance, ready-room guests, etc.):

if(empty(json(triggerBody())?['payload']?['valet_vehicles']), null, int(json(triggerBody())?['payload']?['valet_vehicles']))

Swap valet_vehicles for the field you need, for example:

  • brunch_attendance
  • getting_ready_guests
  • guests (room block count) — only if you allow it blank on draft
Do not use bare int(...) on an empty field int("") fails. Always wrap with if(empty(...), null, int(...)) when the field might be blank.

Yes/No and Choice fields — text, never int

Choice columns (Gift Bags, Valet Needed, Brunch, payment type, etc.) expect text like yes, no, hosted.

Map them as dynamic content or with a simple expression — without int():

json(triggerBody())?['payload']?['bags_providing']
json(triggerBody())?['payload']?['valet_needed']
json(triggerBody())?['payload']?['valet_payment']

If the choice can be blank on draft and SharePoint complains, use null-if-empty (still no int):

if(empty(json(triggerBody())?['payload']?['valet_payment']), null, json(triggerBody())?['payload']?['valet_payment'])

Plain text — usually fine as-is

Names, email, phone, venues, times-as-text can use dynamic content directly, for example:

json(triggerBody())?['payload']?['couple_name']
json(triggerBody())?['payload']?['email']

Empty text is normally OK for Single line of text columns.

Form URL (resume link)

On every Create/Update (Save and Submit), set Form URL to an expression like:

Save draft (uses variable DraftIDFinal — rename if yours differs):

concat(json(triggerBody())?['form_url'], '?draft=', variables('DraftIDFinal'), '&wedding_date=', coalesce(json(triggerBody())?['payload']?['wedding_date'], ''), '&complete_by=', coalesce(json(triggerBody())?['payload']?['complete_by'], ''))

Submit (use your submit draft-id output name):

concat(json(triggerBody())?['form_url'], '?draft=', outputs('DraftID_Submit'), '&wedding_date=', coalesce(json(triggerBody())?['payload']?['wedding_date'], ''), '&complete_by=', coalesce(json(triggerBody())?['payload']?['complete_by'], ''))

Cheat sheet

Column typeEmpty-safe patternNever do this

Number if(empty(...), null, int(...)) int(...) alone on a blank
Choice (yes/no) Text value; optional null-if-empty int(yes/no)
Text Direct map usually fine —
After any expression change Save the flow → open the form → Save once with the field blank → Save again with the field filled → confirm the SharePoint row looks right.

12. If something goes wrong (Power Automate)

Start here when Save/Submit fails, the list stays empty, or the form says “upstream server.”

How to check a run (do this first)

  1. Open Power Automate → flow Wedding Room Block Form - API.
  2. Click Run history (28-day list of attempts).
  3. Open the newest run (or match the time you clicked Save).
  4. Green check = that step worked. Red X = that step failed (read the error text). Grey / “Skipped” = that branch did not run.
  5. Expand Create item / Update item and any Response (200) steps.
Important A run can look mostly green while the form still errors — often because the Response 200 step was Skipped or ran too late (after PDF/email).

Simple decision guide

Form error?→ Open Run history→ Find red / skipped step→ Fix that step→ Save flow → retry form

Symptom → what to do

What you seeLikely causeWhat to try
Form: “Upstream server” / timeout, but flow is green HTTP Response ran too late or was Skipped Move Response 200 to right after SharePoint Create/Update (before PDF convert / email). Place it after ItemLength so both Create and Update paths reply.
First Save works; later Saves fail the same way Response only under Create, not Update Guest/Staff 200 steps must sit outside the Create-only branch — after ItemLength.
Cannot unlock form Wrong code, flow Off, or wrong API URL Confirm flow is On. Check guest vs staff code. Confirm config.js API_URL matches this flow’s HTTP URL.
Create/Update fails mentioning a date column Empty date sent as "" Paste a null-if-empty date expression (Section 11).
Error with int(...) on a yes/no field Choice treated as a number Remove int(); map the choice as text (Section 11).
New list column always blank Column added in SharePoint but not mapped in the flow Follow Section 9 Steps C–E. Refresh Create/Update fields.
Wrong people get (or miss) PDF emails To / Cc on Submit email is outdated Section 10 — update addresses or use a shared mailbox.
Old password still works / new one does not Compose not saved, or wrong Compose edited Section 7 — edit FormPassword / StaffPassword → Save → test unlock.
PDF looks like raw JSON SubmitHTML still dumping payload Replace with the form-style template in FORM-PDF-HTML.md.
Staff does not see “Important dates” Unlocked with guest code Unlock with the staff code.
Couple got no resume email Staff save (silent on purpose), or email step failed Staff Saves do not email. Guest Saves should. Check Run history → Send email step.
Flow shows Failed on SharePoint Column type mismatch or missing required field Read the red error. Fix type (text vs number vs choice) or mapping. Re-test.

Where Response 200 should sit (sketch)

Create or Update item→ Response 200 (form OK)→ HTML / PDF / email (can be slower)

The form only needs the early “OK” reply. PDF and email can finish afterward.

Still stuck? Screenshot the failed step’s error message in Run history and send it to whoever maintains the flow. That one screenshot usually beats a long description.
